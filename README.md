# INSEAD MBA | Class of 26D

This repository is dedicated to academic assignments and coursework for the **INSEAD MBA Class of 26D**. It serves as a structured hub for organizing projects, case studies, and submissions across various modules.

## 📂 Repository Structure

The project is organized by course modules to ensure easy navigation and version control for all assignments.

```text

```

## 🎓 Modules Overview

### Organizational Behavior 2 (OB2)
Focuses on the dynamics of organizations, leadership, and group behavior within a professional context.

## 🛠 Workflow & Usage

1. **New Assignments**: Create a sub-folder within the relevant course directory.
2. **Naming Convention**: Use descriptive names (e.g., `OB2_CaseStudy_01`).
3. **Submissions**: Ensure all required materials are staged and committed before deadlines.

---

> [!TIP]
> Keep the folder names consistent with the course abbreviations provided in the curriculum for better searchability.
